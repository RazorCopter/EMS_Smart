| CMP-01 | The live ESP32 firmware (`v5.1-console-5c`) does not emit an explicit `boot_id` UUID field in `/api/v1/ems/decision` or `ems/decision` MQTT JSON (unlike `07_DECISION_AUDIT_SCHEMA.md`). | CMP-04 | PDF report export relies on browser/print-optimized HTML or lightweight server PDF generation; rich server-rendered ECharts-to-PDF rendering is deferred past MVP if headless Chromium in the API container increases ARM64 image bloat. | Low | CSV and JSON exports are complete and exact; printable report view + structured PDF summary work, while multi-chart vector PDF can be refined later. | Deliver full CSV, JSON, and print-ready / lightweight PDF report export in MVP, keeping API image lean for `linux/amd64` and `linux/arm64`. | Post-MVP C8+ |
| CMP-05 | Battery SOH (`soh`), battery temperature (`battery_temp`), grid current (`grid_a`), and inverter running status (`running`) are not yet populated by the ESP32 FC04 profile (per V51-19). | Low | Battery page and telemetry details must display `Non disponibile` / `unavailable` rather than fabricating or zero-filling these channels. | Keep fields nullable end-to-end and label `measured` vs `derived` vs `configured` vs `provisional` vs `unavailable`. | Firmware G5 |
| CMP-06 | Local prototype runs over plain HTTP inside LAN (`COMPANION_COOKIE_SECURE=false` in `.env.example`). | Medium | Session cookies travel over HTTP if not fronted by a TLS reverse proxy. | Enable TLS termination at reverse proxy and set `COMPANION_COOKIE_SECURE=true` + Entra ID / OIDC before exposing outside trusted LAN. | Hardening / Prod |
