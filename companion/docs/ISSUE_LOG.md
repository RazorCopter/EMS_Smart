## Current verification and closure criteria

| ID | Current status and evidence | Remaining work and acceptance criteria |
|---|---|---|
| CMP-01 | Open in firmware. ESP32 `v5.1-console-6-pred` still omits `boot_id` from the REST decision response. The collector generates and persists a fallback ID for older firmware. | Emit the same explicit ID over REST and MQTT throughout each ESP boot, with a new ID after reboot. Verify collector restart, retained and replayed decisions, deduplication, and older payloads without the field. |
| CMP-02 | Deployment configuration pending in the local Companion checkout. The broker rejects anonymous access and the local Companion environment has no MQTT credentials configured. | Supply authorized read-only broker credentials to the deployment environment. Verify fresh telemetry and decisions in the Companion collector and API, including after reconnect. Keep credentials outside Git. |
| CMP-03 | Implementation available. The [HA package](../deploy/ha/afore_companion_sem.yaml) publishes SEM snapshots and the collector supports MQTT with optional read-only HA REST polling. HA REST is disabled locally. An authenticated 35-second broker listener received eight telemetry messages and seven decisions, with no SEM snapshot during that window. The decision messages also omitted `boot_id`. | Verify the package is loaded in HA, or configure the read-only fallback if needed. Confirm that fresh SEM and ESP SHADOW decisions appear side by side and that unavailable SEM data stays null. Preserve the current SEM automation state and native inverter control. |
| CMP-04 | MVP delivered. CSV, JSON, printable report and lightweight server PDF are available. Rich server-rendered chart PDF remains optional. | If a chart PDF is required, agree on its chart and print layout, then verify the output, architecture support and deployment footprint. |
| CMP-05 | Open in firmware. Live ESP telemetry omits `soh`, `battery_temp`, `grid_a` and `running`. | Qualify Afore FC04 registers and scaling against a trusted reference. Check direction and units where applicable. Preserve null and unavailable provenance where measurement cannot be validated. |
| CMP-06 | Local hardening pending. The checked configuration uses HTTP and has secure cookies disabled. [Security documentation](SECURITY.md) describes TLS termination and optional OIDC. The deployed perimeter was not verified. | Before exposure outside the trusted LAN, verify TLS termination, HTTP redirect and secure cookie behavior on the deployment. Verify viewer and admin access if federation is adopted. |
| CMP-07 | Optional polish. CSS declares the font families with system fallbacks. The web app has no bundled WOFF2 assets. | If consistent cross-platform typography is required, bundle licensed local subsets and verify that the UI makes no external font requests. |

Resolve CMP-02 before validating CMP-03 in the Companion. CMP-01 and CMP-05 can proceed on the firmware branch independently. CMP-06 gates external exposure. CMP-04 and CMP-07 are optional improvements.
