# Hardware baseline

Target is Waveshare ESP32-S3-Relay-1CH with the integrated antenna, Windows COM10. Confidence labels distinguish **official agreement** (documented design), **ROM verified** (direct read on this specimen), **reported device** (Mission 1 attachment), **historical bench** (another board or earlier session), and **pending unit verification** (this specimen).

## COM10 ROM evidence

On 2026-11-18 the user confirmed the bench unit was disconnected from field wiring. `esptool --chip esp32s3 --port COM10 --before usb-reset --after hard-reset --no-stub flash-id` exited successfully. It used the ROM loader and issued a final hardware reset. No flash or eFuse write, Modbus I/O or relay command was performed. There was no instrumented contact or coil measurement during reset.

G1 electronic identification is verified. Visual correlation of PCB revision, product label and antenna population remains open. G3 closes electrical OFF-on-reset and runtime memory/RTC checks. G4 establishes installed bus wiring and timing.
