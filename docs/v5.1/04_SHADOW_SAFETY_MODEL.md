# SHADOW safety model

First release invariant: physical traffic contains only allowlisted Modbus reads, the command result carries `executed=false` and `modbus_write_count=0`, and AUX1 remains disabled and electrically OFF. A transmitted FC04 request uses UART TX and is counted as a read, so distinguish TX frames from Modbus writes in all evidence.

| Boundary | Required implementation |
|---|---|
| ReadOnlyModbusTransport | Public capability is typed `readInputRegisters(slave, range)` with bounded output. Afore uses fixed configured unicast slave and allowlisted ranges; G4 opens the smallest approved FC04 request first. Reject zero/broadcast, illegal range, count/overflow, malformed content, CRC or unexpected response slave/code/size. Treat RTU exceptions and timeout as failures with bounded recovery. Only private UART adapter can transmit complete validated read ADUs. No raw-frame submission, discovery sweep, bridge passthrough or TX-capable capture path. Reuse RTU and guard checks where appropriate. |
| ShadowCommandExecutor | Compiled with no UART, driver, GPIO, AUX or network handles. Accepts typed safety-approved or vetoed plan, returns SIMULATED / NO_ACTION / BLOCKED and immutable executed=false. Constructs no write frames. Only CommandArbiter calls it. |
| Future LiveCommandExecutor | Reserved architectural slot outside v5.1 source selection. No mode setter, route, subscription, NVS field, update handler, or serial console command can activate it. Qualification is G11. |
| Build composition | Dedicated V5.1 diagnostics and SHADOW allowlists. Require SHADOW build constant and reject combinations with live executor, raw bus capture/multiple owners, DRM, legacy command dispatcher, dynamic write profile or OTA. Compile separately scoped read driver/transport and off-only AUX. Host tests share the same policy sources. Legacy `waveshare-afore-shadow` is evidence for remediation only. |
| Safety Engine | Validate coherent and fresh essentials, BMS limits if confirmed, SOC reserve/ceiling, power limits, import/export policy, fault statuses, time quality and candidate expiry. Hard pass/fail or derating precedes deadband/ramp and is repeated on the final plan. If no feasible bound remains, output a veto and no command. Missing limit/fault data for a dependent strategy yields Safe Mode or a proven narrower policy. Severe faults and unknown critical input clamp immediately, including at boot. |

## Required proofs

1. Pin target composition and archive actual compile/link commands, source allowlist, tool versions, ELF, map, binary, partition manifest and SHA-256. Verify linked objects, `nm -C` symbols and call/reference paths (retaining a map and non-stripped audit ELF). Fail on writer/executor/legacy command objects, Modbus write encoders, relay ON path or disallowed network routes/handlers. With LTO, inspect references and disassembly at the hardware sink as well as symbols. Strings and macro assertions contribute evidence alongside source/link and bus checks.
2. Positive compile control followed by negative tests with expected diagnostics for live headers, runtime mode setter, raw TX, writable profile and energized AUX. A compile error caused by missing headers/toolchain fails the test. The legacy M3A probe accepts any compile failure and needs a stricter harness.
3. Host lower-transport spy tests for approved FC04 and rejection of FC05/06/0F/10/16/17, broadcasts, malformed requests, CRC, invalid ranges, random input, legacy/raw endpoints, altered config and replay/expiry. Assert zero lower-layer bytes for rejected input. Scope UART/RS485 during diagnostic no-TX run and during allowed G4 proof; independently decode frames. A software counter alone cannot pass G4/G10.
4. Test source precedence, safe mode, reboot, telemetry corruption/stale, error recovery and restarts. Test API/MQTT responses with `executed=false`, null applied setpoint, zero writes and no live/actuate route. Reject attempts to set AUX through config or service boundaries, record denial without exposing credentials. Bench-verify physical OFF as in [AUX abstraction](05_AUX_ABSTRACTION.md).
